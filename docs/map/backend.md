# Backend source map — `backend/src/main/java/thumbnailer/` (Java 27, Spring Boot 4.1, Undertow)

[↑ INDEX](../../INDEX.md) · rules: [backend/CLAUDE.md](../../backend/CLAUDE.md) · design: [ARCHITECTURE §2](../ARCHITECTURE.md#2-backend-package-thumbnailer) · wire: [§3](../ARCHITECTURE.md#3-transport)

Legend: **port** = domain interface, **SPI** = extension point (impls collected as beans), `@C` = Spring bean.
Most classes are package-private; public = used across packages.

## Pipeline

```
ScanService.start(paths→scopes) ─▶ Reconciler.begin (retainRoots) ─▶ Settings.locate(scope) ─▶ AlbumDiscovery.walk(physical scope) ─Found(path,kind)─▶ Reconciler.Pass.reconcile(canonical path) (virtual "index-N", ≤ index-threads) ─▶ Pass.prune(complete scopes)
   └▶ Disks SCAN lane turn ─▶ Containers.open ─▶ AlbumIndexer.index (ImageProbe, Metadata chain, CoverSelector, AlbumService.renderCover: queue → read, turn ends → decode ≤ covers Limiter)
        └▶ AlbumService.commit (prior = stored album or recalled tombstone) ─▶ AlbumRepository.save + BlobStore.put (tagged cover) ─▶ AlbumEvent ─▶ AlbumSocket broadcast
WS /ws: AlbumSocket.handle(Request) ─▶ AlbumRepository (search/find/facets/folders) | AlbumService.patch | ScanService | SettingsStore | Browse | Library (─▶ ThumbnailerApplication.restart)
        | CatalogRequest ─▶ CatalogApi (Catalog, then AlbumService.patch per rewritten album; bulk patch, list links, copies, compareCopies ─▶ Containers.openRaw) | OpsRequest ─▶ OpsApi (FileOps ─▶ Gate, "ops" thread) | PhotosRequest ─▶ PhotosApi (Catalog marks)
HTTP /img/{id}/…: ImageController ─▶ AlbumService.cover (stored, else render + store) / thumb (Disks VIEW lane turn → queue → read → decode ≤ thumbs Limiter, not stored; a sequential archive: its Gallery pass) | Containers.open (original)
```

## [album/](../../backend/src/main/java/thumbnailer/album/) — domain records, ports, single mutation owner

- [Link.java](../../backend/src/main/java/thumbnailer/album/Link.java) — `Album.links` entry `(entity, role: EntityKind, name, alias?)`.
- [AlbumMeta.java](../../backend/src/main/java/thumbnailer/album/AlbumMeta.java) — one metadata layer (+ `genres`); `over()` (edit merge, null falls through), `orElse()` (extractor merge, blank falls through, tags and genres union), `effective()`, `withDate()`, `tag()` normalizer.
- [AlbumPatch.java](../../backend/src/main/java/thumbnailer/album/AlbumPatch.java) — user edit; null = unchanged, `""`/`[]` = explicit empty, `cover:""` unpins; `date` (`YYYY-MM-DD`/`YYYY-MM`/`YYYY` → first day, `""` clears, else `IllegalArgumentException`), `genres`, `hidden`, `addTags`/`removeTags` (on the effective tags); `edit(edited, tags)` → the new edited layer.
- [AlbumQuery.java](../../backend/src/main/java/thumbnailer/album/AlbumQuery.java) — search criteria (+ `genres entities missing hidden duplicates`) + nested `enum Sort` (14 values: 7 fields × 2 directions); clamps limit ≤1000 (default 100), sort default NEWEST; `page(offset, limit)`.
- [AlbumRepository.java](../../backend/src/main/java/thumbnailer/album/AlbumRepository.java) — **port**: `search count facets find byRoot stamps byContentId rootStats folders entries entry saveEntries save delete recall reroot relocate purge stats compact`, default `select(ids, query)` (≤ `SELECT_CAP` 500, more fails); directory arguments select by path prefix (`root` column informational); hidden albums out of search/count/facets/folders/stats and the `rootStats` counts, never out of `stamps`/`byRoot`; albums read back carry `links` and `copies`; `stamps(dir)` = path → `Stamp(id, signature)` for scans; `save(a, entries, Resolution, Save)` (`Save(visibleBefore, visibleAfter, suspend, nameMap)`: the save counts its links of every role itself and moves the photo marks of renamed entries; default `save(a, entries)` = `Resolution.NONE` + `Save.UNCOUNTED`), `save(a, null)` keeps entries; `saveEntries(id, entries)` rewrites the entry list alone (flags learned later); `delete` leaves a `Tombstone(id, revision, rating, cover, coverPinned, edited, seq, hidden)` per (content, id) (`of(Album)`), `recall(contentId)` peeks at the newest, `save` consumes the tombstones of its id (same tx); `folders(parent)` → `Folder(name, path, albums, nested)`; `Stats(albums, images, imageBytes, lastIndexedAt, liveBytes, fileBytes)`; `compact()` = full compaction at close.
- [BlobStore.java](../../backend/src/main/java/thumbnailer/album/BlobStore.java) — **port**: covers by album id: `put get remove` (exact key); a regenerable cache; `stats()` → `Stats(count, liveBytes, fileBytes)`; `compact()` (synchronous, best effort).
- [AlbumService.java](../../backend/src/main/java/thumbnailer/album/AlbumService.java) — `@C` **only writer**: `commit(base, …)` (scan: prior state = stored album it matched, else a recalled tombstone whose id is not live, as one `Tombstone`; the save consumes it), `commit(prior, …, nameMap)` (an operation asserts the identity: adopts the album stored under `prior`'s id, re-read under the lock, `prior` only if the row is gone; pin and photo marks follow renamed entries), both through `store` → `save` (`Catalog.resolving` → `repo.save(…, resolution, Save(visible before/after, suspended while a scan holds the `Gate`, nameMap))` under the catalog read lock, re-read), `patch(id, AlbumPatch)` (date, hidden, genres, add/remove tags) = `patch(id, Function<Album, AlbumPatch>)` (the edit computed from the album re-read under its stripe lock: a text edit over the current text; empty when gone or null), `setFlags(albumId, name, flags)` (one `saveEntries` under the lock, no revision: what a metadata read learned) `remove` (under the stripe lock, `repo.delete` runs inside `Catalog.reading`, the read lock: its count deltas cannot interleave with a list change; `removeBelow`/`retainRoots` loop over it), `relocate rebase removeBelow` (each move bumps `revision`; `rebase` = `relocate` per album under its lock), `quiesce quiesceBelow release busy read` (`read(id)` → `Reading`: every `/img` read of an album's files, counted per album in `readers` and refused once busy; `quiesce` marks busy, closes the albums' gallery passes and waits ≤ 5 s for the reads in flight, then logs and goes on; busy: `cover`/`thumb`/`read`/a render throw `IllegalStateException(BUSY)`, no gallery pass starts), `retainRoots`, public `lane` (stale root: `reroot` to the configured root covering it, remove the rest); renders `cover storedCover renderCover(container, name, turn) thumb` (→ `Thumb`) as a pipeline: the read happens in a disk turn (`Disks.Hold`, the scan's or a `VIEW` lane's) and takes a place in a queue (`coverQueue`/`thumbQueue`, 2 × threads), the turn ends with the read, then decode/resize/encode under `coverSlots`/`thumbSlots` (threads), all `Limiter`s sized from `Settings.covers/thumbs`; order turn → queue → slot; `thumb` of an `ARCHIVE` album asks `galleries` (access-ordered, ≤ 4 albums, keyed by revision + thumbs epoch + threads + `cryKey`; `sequential()` checked outside the lock, the first racing request publishes and starts its `Gallery`, a read of the album until its pass ends) for a gallery; `closeGalleries` on `ContextClosedEvent` sets `closing` (no gallery starts after it); 64 striped locks; publishes `AlbumEvent` after the lock; cover values = 8-byte state tag (wyhash seeded by the bytes' render epoch, of cover + signature) + `[len 4]` + bytes, or legacy `[tag][webp]` for `Render.LEGACY_EPOCH`; checked on read (tag + length/RIFF size); disk through `Settings.locate`.
- [Gallery.java](../../backend/src/main/java/thumbnailer/album/Gallery.java) — the entry thumbnails of a `sequential()` archive from one `heads(…, MAX)` pass in packing order on a virtual thread `gallery` (the 7-Zip pass owner): holds the `VIEW` turn while reading, queue place per file, decode on a virtual thread under the slots; paced: runs while an asked entry is unread, else parks `LOOKAHEAD` (24) thumbnails ahead without the turn; on its way to an asked entry renders at most that lookahead of unasked ones and passes over the rest (≤ 24 untaken thumbnails held); `start()` after publishing; `take(name)` waits ≤ 5 min and forgets the thumbnail (null = taken before, passed over, not in the archive or closed → the caller renders alone); idle 1 min / evicted / shutdown → `close()` (drops what nobody took); entries never reached fail with `CancellationException`; the `ended` hook runs on the pass after its container closed.
- [AlbumEvent.java](../../backend/src/main/java/thumbnailer/album/AlbumEvent.java) (sealed `Changed|Removed`) · [Entry.java](../../backend/src/main/java/thumbnailer/album/Entry.java) (`index name bytes mtime width height shotAt flags`, `META_KNOWN META`) · [Facets.java](../../backend/src/main/java/thumbnailer/album/Facets.java) (+ `genres`, empty until B1).

## [source/](../../backend/src/main/java/thumbnailer/source/) — where albums live

- [AlbumContainer.java](../../backend/src/main/java/thumbnailer/source/AlbumContainer.java) — `Closeable`: `items() images() open(name)`, `head(name, limit)` (leading bytes), `read(name, arena)` (whole file as a `MemorySegment`), `heads(names, limit, HeadSink)` (in on-disk/packing order; unreadable files skipped; the sink may run inside a decompression, on another thread: it must not read the container), `extract(names, EntrySink)` (whole files, fail-closed: a name listed twice fails too, before anything is read; default loop over `open`), `sequential()` (one file costs a pass over those packed before it: read several only through `heads`), `cpuBound()` (one compressed pass: reading costs CPU, not disk time), `keyTag()` (key state of its encrypted members, "" by default: see `Cry`); `signature()` (all files incl. sidecars, with mtime) vs `contentId()` (images, name+bytes), both wyhash final4 hex; static `archiveSignature(file, exclusions)` (size + mtime + globs: an archive rescans by `stat`); `IMAGE_EXTENSIONS` (incl. `cry`).
- [ContainerFactory.java](../../backend/src/main/java/thumbnailer/source/ContainerFactory.java) — **SPI** `kind() accepts(path) open(path, exclusions)`; impls nested `DirectoryContainer.Factory`, `ZipContainer.Factory`, `SevenZipContainer.Factory`.
- [Containers.java](../../backend/src/main/java/thumbnailer/source/Containers.java) — `@C` factory registry: `archive(path)`, `open(kind, path, excl)` (every container comes back wrapped by `Cry`), `openRaw(kind, path)` (unwrapped, `Exclusions.NONE`: file operations only); static `normalize()` (abs, `/`), `prefix()`, `within(path, dir)` (case-insensitive), `rebase(path, from, to)`.
- [Cry.java](../../backend/src/main/java/thumbnailer/source/Cry.java) — `@C` xanderView's encrypted `.cry` images (`int32 F | byte 1 | AES-128/ECB(int16 L − 32768 | name[L] | image[F])`, L = C − 2 − F; key = PBKDF2-SHA1(trimmed password, "z!a3", 1024, 128)): static `is(name) key(password) fingerprint(key)` (8 hex of SHA-256, also the signature tag) `encrypt(in, size, name, key, out)` (the format's writer, streaming 64 KiB chunks; a padded name over 32767 bytes or a wrong byte count throws, never clamps; `encrypt(plain, name, key)` wraps it) `decrypt(in, size, key, out)` (streaming, header check, returns the embedded name; `decrypt(file, key)` wraps it) `plainName(head, key)` (embedded original name; `plainName(head, size, key)` also refuses a key the header check of `decrypt` would) `signature(container) matches(stored, container)` (a key tag stored and `+locked` now still matches: no key never re-indexes), `wrap(container)` (key from `settings.cryKey`, captured at open) → private `Decrypted` decorator: `open head heads read` decrypt `.cry` members (heads into fresh arrays, 16-aligned prefix alone; whole files in 64 KiB chunks through two heap buffers back into the native segment; a per-call `Cipher`), `images()` without a key hides them, `keyTag()` = `+locked` | `+` + 8 hex of SHA-256(key); one private `header(F, L, size)` check for every reader (`decrypt`, `plainName`, `Decrypted`), before the name is read: F ≥ 0, L ≤ 32767 and, with the size known, `L == size − 7 − F` (sizes from `items()`, listed before a `heads` pass); it refuses a wrong key, the member is skipped and one warning per container is logged at `close()`; `signature contentId sequential cpuBound` delegate.
- [DirectoryContainer.java](../../backend/src/main/java/thumbnailer/source/DirectoryContainer.java) (listed by a one-level `walkFileTree`, following links: size and mtime from the directory listing on Windows; `read` = one channel read into arena memory, `head` = one channel read) · [ZipContainer.java](../../backend/src/main/java/thumbnailer/source/ZipContainer.java) (JDK `ZipFile` opened and listed on first use, `heads` in central-directory order, `read` = arena memory through a 64 KiB buffer, stat signature memoized before the first read) · [Kind.java](../../backend/src/main/java/thumbnailer/source/Kind.java) (`DIRECTORY|ZIP|ARCHIVE`).
- [SevenZipContainer.java](../../backend/src/main/java/thumbnailer/source/SevenZipContainer.java) — `ARCHIVE` (`EXTENSIONS`: rar 7z tar iso gz tgz bz2 tbz tbz2 xz txz z taz) through 7-Zip-JBinding 26.03 (`Native.init()`: `LibraryLoader.load` + `SevenZip.initLoadedLibraries`); opened on first use, stat signature memoized before reading; random-access archives extract per file and stop 7-Zip after the asked bytes; `heads` in packing order (item index), solid ones in one pass delivering each head from inside it and keeping heads ≤ 128 KiB (64 MiB budget) for later `head` calls; `sequential()` = solid or wrapped (from the header, no listing pass); `cpuBound()` = sequential and not stored (`STORED`: 7z Copy, RAR m0); a tar inside gzip/bzip2/xz/Z (`wrapped`: inner `.tar` or a `TARRED` file name) is listed by one decompression that keeps ≤ 128 KiB heads (64 MiB budget), while `read`/`head` of a named file stream to it without a listing; `Pass` = one extraction (stop flag, sink failure, the owner thread's interrupt via `setCompleted`): 7-Zip calls the output streams from its own threads (seen with multi-threaded LZMA2), so callbacks touch no confined state and `read` fills a shared arena handed to the caller's arena (`reinterpret`); `extract` = one native pass over the named files in packing order (a wrapped tar through its visitor), each buffered whole (the buffer follows the bytes past 16 MiB, never a header's size alone) and handed on as it completes, possibly on a 7-Zip thread; fail-closed (missing, damaged, mis-sized; `refused` names: listed twice, or a `SYM_LINK`/`HARD_LINK` entry, whose bytes 7-Zip gives as the target name or nothing; a wrapped tar whose stream result is bad after its files: `Pass.damaged`, e.g. a gzip CRC); an empty archive opens (item 0 read only when there is one); public only for `loadNative()` (the out-archive side of `ops/pack` initializes through `Native`); Windows backslash paths → `/`.
- [TarStream.java](../../backend/src/main/java/thumbnailer/source/TarStream.java) — push tar parser fed by 7-Zip's output (`ISequentialOutStream`): `Visitor{entry data end}` per regular file; ustar prefix, GNU 'L' long names, pax `path`, base-256 sizes.
- [Disks.java](../../backend/src/main/java/thumbnailer/source/Disks.java) — public `@C` (public constructor, for tests): `disk(physicalRoot, Storage)` → `Disk(key, ssd)` (detected once per reachable root and logged; `Storage AUTO|SSD|HDD` overrides): Windows kernel32 over FFM without admin (`GetVolumePathNameW` → `GetDriveTypeW` remote → HDD → `GetVolumeNameForVolumeMountPointW` → `CreateFileW` access 0 → `IOCTL_STORAGE_QUERY_PROPERTY` seek penalty, `IOCTL_STORAGE_GET_DEVICE_NUMBER` key `diskN`), Linux sysfs `queue/rotational` of the mount device or its disk, macOS `diskutil info` "Solid State"; network file systems, unknown and failures = HDD; `lane(disk, Use SCAN|VIEW)` → `Lane` (fair `Semaphore(hdd-readers)` on an HDD, no gate on an SSD) `enter()` → `Hold` (`close` idempotent, so a turn can be handed on; `Hold.NONE`); on an HDD a `SCAN` lane gives way to the `VIEW` lane of the same disk: `enter()` and `giveWay()` (between a scan's reads) return once the UI has not read for `QUIET` (300 ms).
- [Exclusions.java](../../backend/src/main/java/thumbnailer/source/Exclusions.java) — `*` globs (match across `/`, case-insensitive) on normalized absolute canonical paths; `rebased(physical, canonical)` tests paths under a mapped root in their canonical form.

## [image/](../../backend/src/main/java/thumbnailer/image/)

- [ImageProbe.java](../../backend/src/main/java/thumbnailer/image/ImageProbe.java) — `probe(container, name)` / `probe(head, name, Source)` from the first `HEAD` (128 KiB) bytes: `probe(head)` (pure: `Header` for JPEG/TIFF/PNG/GIF/BMP, WebP via its bitstream header, else null), else `read(Source)` (metadata-extractor + ImageIO header, one open; reopens past the head); `Source` = how to open the file again; `exif(head)` (marker walk for JPEG, metadata-extractor otherwise); `decode(stream, name, exif, body)` for the ImageIO fallback; records `Probe`, `Exif`.
- [Header.java](../../backend/src/main/java/thumbnailer/image/Header.java) — public record; `parse(MemorySegment)` → `(width, height, Exif, meta)` from a prefix (`meta`: a JPEG APP1, a TIFF's IFDs, a PNG `eXIf` seen; public `meta(head)` → null when unparsed): JPEG markers to the SOFn (+ APP1 Exif), TIFF IFD0 (size, Orientation, Artist; Exif-IFD DateTimeOriginal; both byte orders), PNG IHDR + `eXIf` before IDAT, GIF logical screen, BMP DIB header; null for other formats, a zero size or facts past the prefix.
- [Thumbnailer.java](../../backend/src/main/java/thumbnailer/image/Thumbnailer.java) — `@C` `render(data, name, Render)` → `Thumb(bytes, format, epoch, portrait)` from the file in memory (the caller reads it, so its disk turn ends before the decode; `render(container, …)` reads in a confined arena first) → JPEG: `TurboJpeg.decode` at the smallest DCT scale ≥ `GAP` (1.5) × target (CMYK/12-bit → ImageIO); WebP: `WebP.decode`; else ImageIO subsampled to ≤ 2× → `Resampler` → `Pixels.oriented` (EXIF 2–8) → `WebP.encode` / `TurboJpeg.encode`; longer side `spec.size`, proportional, no upscale; the constructor loads both natives (fails fast), logs `Resampler.PATH` and starts `Resampler.warmUp` on the daemon thread `resampler-warmup`.
- [TurboJpeg.java](../../backend/src/main/java/thumbnailer/image/TurboJpeg.java) — libjpeg-turbo 3.2 C API over FFM (ordinary `tj3*` downcalls on native memory: a critical 10-50 ms decode held off the other renders' safepoints; buffers from `tj3Alloc`, uninitialized): `isJpeg`, `decode(segment, minLonger)` (DCT scale 1/8, 1/4, 1/2 or 1, full size for lossless JPEGs; fast IDCT + upsampling; `TJPF_BGRX`, one bulk copy into `Pixels`; libjpeg warnings accepted), `encode(Pixels, quality)` (4:2:0, worst-case buffer, no realloc).
- [WebP.java](../../backend/src/main/java/thumbnailer/image/WebP.java) — over the vendored `NativeWebP`: `isWebP features decode` (stills; alpha → white; an animation throws so ImageIO decodes its first frame) `encode` (lossy, single-threaded, BGRX import without a copy).
- [Pixels.java](../../backend/src/main/java/thumbnailer/image/Pixels.java) — record `(argb, width, height)`, packed `0x??RRGGBB`, the one layout decode → resample → encode; `of(BufferedImage)` (ImageIO fallback, on white), `onWhite()`, `oriented(exif)` (index remapping).
- [Render.java](../../backend/src/main/java/thumbnailer/image/Render.java) — spec record `(format WEBP|JPEG, quality 1..100, size 64..4096, threads 0..64)`, `Format.mediaType()`, `permits()` (0 = CPUs), `epoch()` (format/size/quality), `LEGACY_EPOCH` = `(WEBP, 75, 512)`; defaults `COVERS`, `THUMBS`.
- [Limiter.java](../../backend/src/main/java/thumbnailer/image/Limiter.java) — fair `Semaphore` (a waiter may hold a disk turn) with `resize(permits)` (grow = release, shrink = `reducePermits`) and `enter(permits)` (resize + acquire; interrupt → `InterruptedIOException`).
- [Resampler.java](../../backend/src/main/java/thumbnailer/image/Resampler.java) — `resize(Pixels, w, h, boxed[, simd])` both directions, Pillow geometry: power-of-two `box` (2/4/8, cropped to whole boxes, at most 1/64 of an axis) while ≥ 1.9x remains, then Lanczos3 (also for `boxed` = DCT-scaled input), else Keys cubic a = −0.55; Q7 with R|B in 16-bit fields (Q22 for kernels > 24 taps); nested `Simd` (Vector API: shuffle/blend plans up to ratio 4, gathers beyond, SIMD box) used when `SIMD` (module present, C2 available per `c2()`: HotSpot `UseCompiler` and `TieredStopAtLevel` ≥ 4, ≥ 8 int lanes), else scalar loops with the same bits; `warmUp()` runs the SIMD kernel shapes real images take until C2 compiled them (warming tiny gather/Q22 shapes as well left the main shape 3x slower) (interpreted Vector API code made the first album after start 3x slower); `PATH` names the path taken and why. Chosen with [scalebench](../../scalebench/README.md).

## [natives/](../../backend/src/main/java/thumbnailer/natives/) and the vendored webp4j surface
