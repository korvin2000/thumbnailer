# Backend source map — `backend/src/main/java/thumbnailer/` (Java 27, Spring Boot 4.1, Undertow)

[↑ INDEX](../../INDEX.md) · rules: [backend/CLAUDE.md](../../backend/CLAUDE.md) · design: [ARCHITECTURE §2](../ARCHITECTURE.md#2-backend-package-thumbnailer) · wire: [§3](../ARCHITECTURE.md#3-transport)

Legend: **port** = domain interface, **SPI** = extension point (impls collected as beans), `@C` = Spring bean.
Most classes are package-private; public = used across packages.

## Pipeline

```
ScanService.start(paths→scopes) ─▶ Reconciler.begin (retainRoots) ─▶ Settings.locate(scope) ─▶ AlbumDiscovery.walk(physical scope) ─Found(path,kind)─▶ Reconciler.Pass.reconcile(canonical path) (virtual "index-N", ≤ index-threads) ─▶ Pass.prune(complete scopes)
   └▶ Disks SCAN lane turn ─▶ Containers.open ─▶ AlbumIndexer.index (ImageProbe, Metadata chain, CoverSelector, AlbumService.renderCover: queue → read, turn ends → decode ≤ covers Limiter)
        └▶ AlbumService.commit (prior = stored album or recalled tombstone) ─▶ AlbumRepository.save + BlobStore.put (tagged cover) ─▶ AlbumEvent ─▶ AlbumSocket broadcast
WS /ws: AlbumSocket.handle(Request) ─▶ AlbumRepository (search/find/facets/folders) | AlbumService.patch | ScanService | SettingsStore | Browse | Library (─▶ ThumbnailerApplication.restart)
HTTP /img/{id}/…: ImageController ─▶ AlbumService.cover (stored, else render + store) / thumb (Disks VIEW lane turn → queue → read → decode ≤ thumbs Limiter, not stored; a sequential archive: its Gallery pass) | Containers.open (original)
```

## [album/](../../backend/src/main/java/thumbnailer/album/) — domain records, ports, single mutation owner

- [Album.java](../../backend/src/main/java/thumbnailer/album/Album.java) — wire/store record (+ server-only `Internal(contentId, signature, extracted, edited)`); `withEdits()` recomputes effective fields.
- [AlbumMeta.java](../../backend/src/main/java/thumbnailer/album/AlbumMeta.java) — one metadata layer; `over()` (edit merge, null falls through), `orElse()` (extractor merge, blank falls through, tags union), `effective()`, `tag()` normalizer.
- [AlbumPatch.java](../../backend/src/main/java/thumbnailer/album/AlbumPatch.java) — user edit; null = unchanged, `""`/`[]` = explicit empty, `cover:""` unpins. No date field.
- [AlbumQuery.java](../../backend/src/main/java/thumbnailer/album/AlbumQuery.java) — search criteria + nested `enum Sort` (14 values: 7 fields × 2 directions); clamps limit ≤1000 (default 100), sort default NEWEST.
- [AlbumRepository.java](../../backend/src/main/java/thumbnailer/album/AlbumRepository.java) — **port**: `search count facets find byRoot stamps byContentId rootStats folders entries entry save delete recall reroot stats compact`; directory arguments select by path prefix (`root` column informational); `stamps(dir)` = path → `Stamp(id, signature)` for scans; `save(a, null)` keeps entries; `delete` leaves a `Tombstone(id, revision, rating, cover, coverPinned, edited)` (`of(Album)`), `recall(contentId)` peeks at it, `save` consumes the tombstones of its id (same tx); `folders(parent)` → `Folder(name, path, albums, nested)`; `Stats(albums, images, imageBytes, lastIndexedAt, liveBytes, fileBytes)`; `compact()` = full compaction at close.
- [BlobStore.java](../../backend/src/main/java/thumbnailer/album/BlobStore.java) — **port**: covers by album id: `put get remove` (exact key); a regenerable cache; `stats()` → `Stats(count, liveBytes, fileBytes)`; `compact()` (synchronous, best effort).
- [AlbumService.java](../../backend/src/main/java/thumbnailer/album/AlbumService.java) — `@C` **only writer**: `commit` (prior state = stored album it matched, else a recalled tombstone whose id is not live, as one `Tombstone`; the save consumes it), `patch remove`, `retainRoots` (stale root: `reroot` to the configured root covering it, remove the rest); renders `cover storedCover renderCover(container, name, turn) thumb` (→ `Thumb`) as a pipeline: the read happens in a disk turn (`Disks.Hold`, the scan's or a `VIEW` lane's) and takes a place in a queue (`coverQueue`/`thumbQueue`, 2 × threads), the turn ends with the read, then decode/resize/encode under `coverSlots`/`thumbSlots` (threads), all `Limiter`s sized from `Settings.covers/thumbs`; order turn → queue → slot; `thumb` of an `ARCHIVE` album asks `galleries` (access-ordered, ≤ 4 albums, keyed by revision + thumbs epoch + threads + `cryKey`; `sequential()` checked outside the lock, the first racing request publishes and starts its `Gallery`) for a gallery; `closeGalleries` on `ContextClosedEvent` sets `closing` (no gallery starts after it); 64 striped locks; publishes `AlbumEvent` after the lock; cover values = 8-byte state tag (wyhash seeded by the bytes' render epoch, of cover + signature) + `[len 4]` + bytes, or legacy `[tag][webp]` for `Render.LEGACY_EPOCH`; checked on read (tag + length/RIFF size); disk through `Settings.locate`.
- [Gallery.java](../../backend/src/main/java/thumbnailer/album/Gallery.java) — the entry thumbnails of a `sequential()` archive from one `heads(…, MAX)` pass in packing order on a virtual thread `gallery` (the 7-Zip pass owner): holds the `VIEW` turn while reading, queue place per file, decode on a virtual thread under the slots; paced: runs while an asked entry is unread, else parks `LOOKAHEAD` (24) thumbnails ahead without the turn; on its way to an asked entry renders at most that lookahead of unasked ones and passes over the rest (≤ 24 untaken thumbnails held); `start()` after publishing; `take(name)` waits ≤ 5 min and forgets the thumbnail (null = taken before, passed over, not in the archive or closed → the caller renders alone); idle 1 min / evicted / shutdown → `close()` (drops what nobody took); entries never reached fail with `CancellationException`.
- [AlbumEvent.java](../../backend/src/main/java/thumbnailer/album/AlbumEvent.java) (sealed `Changed|Removed`) · [Entry.java](../../backend/src/main/java/thumbnailer/album/Entry.java) (`index name bytes mtime width height shotAt`) · [Facets.java](../../backend/src/main/java/thumbnailer/album/Facets.java).

## [source/](../../backend/src/main/java/thumbnailer/source/) — where albums live

- [AlbumContainer.java](../../backend/src/main/java/thumbnailer/source/AlbumContainer.java) — `Closeable`: `items() images() open(name)`, `head(name, limit)` (leading bytes), `read(name, arena)` (whole file as a `MemorySegment`), `heads(names, limit, HeadSink)` (in on-disk/packing order; unreadable files skipped; the sink may run inside a decompression, on another thread: it must not read the container), `sequential()` (one file costs a pass over those packed before it: read several only through `heads`), `cpuBound()` (one compressed pass: reading costs CPU, not disk time), `keyTag()` (key state of its encrypted members, "" by default: see `Cry`); `signature()` (all files incl. sidecars, with mtime) vs `contentId()` (images, name+bytes), both wyhash final4 hex; static `archiveSignature(file, exclusions)` (size + mtime + globs: an archive rescans by `stat`); `IMAGE_EXTENSIONS` (incl. `cry`).
- [ContainerFactory.java](../../backend/src/main/java/thumbnailer/source/ContainerFactory.java) — **SPI** `kind() accepts(path) open(path, exclusions)`; impls nested `DirectoryContainer.Factory`, `ZipContainer.Factory`, `SevenZipContainer.Factory`.
- [Containers.java](../../backend/src/main/java/thumbnailer/source/Containers.java) — `@C` factory registry: `archive(path)`, `open(kind, path, excl)` (every container comes back wrapped by `Cry`); static `normalize()` (abs, `/`), `prefix()`, `within(path, dir)` (case-insensitive), `rebase(path, from, to)`.
- [Cry.java](../../backend/src/main/java/thumbnailer/source/Cry.java) — `@C` xanderView's encrypted `.cry` images (`int32 F | byte 1 | AES-128/ECB(int16 L − 32768 | name[L] | image[F])`, L = C − 2 − F; key = PBKDF2-SHA1(trimmed password, "z!a3", 1024, 128)): static `is(name) key(password) fingerprint(key)` (8 hex of SHA-256, also the signature tag) `signature(container) matches(stored, container)` (a key tag stored and `+locked` now still matches: no key never re-indexes), `wrap(container)` (key from `settings.cryKey`, captured at open) → private `Decrypted` decorator: `open head heads read` decrypt `.cry` members (heads into fresh arrays, 16-aligned prefix alone; whole files in 64 KiB chunks through two heap buffers back into the native segment; a per-call `Cipher`), `images()` without a key hides them, `keyTag()` = `+locked` | `+` + 8 hex of SHA-256(key); header check `L == size − 7 − F` (sizes from `items()`, listed before a `heads` pass) refuses a wrong key, the member is skipped and one warning per container is logged at `close()`; `signature contentId sequential cpuBound` delegate.
- [DirectoryContainer.java](../../backend/src/main/java/thumbnailer/source/DirectoryContainer.java) (listed by a one-level `walkFileTree`, following links: size and mtime from the directory listing on Windows; `read` = one channel read into arena memory, `head` = one channel read) · [ZipContainer.java](../../backend/src/main/java/thumbnailer/source/ZipContainer.java) (JDK `ZipFile` opened and listed on first use, `heads` in central-directory order, `read` = arena memory through a 64 KiB buffer, stat signature memoized before the first read) · [Kind.java](../../backend/src/main/java/thumbnailer/source/Kind.java) (`DIRECTORY|ZIP|ARCHIVE`).
- [SevenZipContainer.java](../../backend/src/main/java/thumbnailer/source/SevenZipContainer.java) — `ARCHIVE` (`EXTENSIONS`: rar 7z tar iso gz tgz bz2 tbz tbz2 xz txz z taz) through 7-Zip-JBinding 26.03 (`Native.init()`: `LibraryLoader.load` + `SevenZip.initLoadedLibraries`); opened on first use, stat signature memoized before reading; random-access archives extract per file and stop 7-Zip after the asked bytes; `heads` in packing order (item index), solid ones in one pass delivering each head from inside it and keeping heads ≤ 128 KiB (64 MiB budget) for later `head` calls; `sequential()` = solid or wrapped (from the header, no listing pass); `cpuBound()` = sequential and not stored (`STORED`: 7z Copy, RAR m0); a tar inside gzip/bzip2/xz/Z (`wrapped`: inner `.tar` or a `TARRED` file name) is listed by one decompression that keeps ≤ 128 KiB heads (64 MiB budget), while `read`/`head` of a named file stream to it without a listing; `Pass` = one extraction (stop flag, sink failure, the owner thread's interrupt via `setCompleted`): 7-Zip calls the output streams from its own threads (seen with multi-threaded LZMA2), so callbacks touch no confined state and `read` fills a shared arena handed to the caller's arena (`reinterpret`); Windows backslash paths → `/`.
- [TarStream.java](../../backend/src/main/java/thumbnailer/source/TarStream.java) — push tar parser fed by 7-Zip's output (`ISequentialOutStream`): `Visitor{entry data end}` per regular file; ustar prefix, GNU 'L' long names, pax `path`, base-256 sizes.
- [Disks.java](../../backend/src/main/java/thumbnailer/source/Disks.java) — public `@C` (public constructor, for tests): `disk(physicalRoot, Storage)` → `Disk(key, ssd)` (detected once per reachable root and logged; `Storage AUTO|SSD|HDD` overrides): Windows kernel32 over FFM without admin (`GetVolumePathNameW` → `GetDriveTypeW` remote → HDD → `GetVolumeNameForVolumeMountPointW` → `CreateFileW` access 0 → `IOCTL_STORAGE_QUERY_PROPERTY` seek penalty, `IOCTL_STORAGE_GET_DEVICE_NUMBER` key `diskN`), Linux sysfs `queue/rotational` of the mount device or its disk, macOS `diskutil info` "Solid State"; network file systems, unknown and failures = HDD; `lane(disk, Use SCAN|VIEW)` → `Lane` (fair `Semaphore(hdd-readers)` on an HDD, no gate on an SSD) `enter()` → `Hold` (`close` idempotent, so a turn can be handed on; `Hold.NONE`); on an HDD a `SCAN` lane gives way to the `VIEW` lane of the same disk: `enter()` and `giveWay()` (between a scan's reads) return once the UI has not read for `QUIET` (300 ms).
- [Exclusions.java](../../backend/src/main/java/thumbnailer/source/Exclusions.java) — `*` globs (match across `/`, case-insensitive) on normalized absolute canonical paths; `rebased(physical, canonical)` tests paths under a mapped root in their canonical form.

## [image/](../../backend/src/main/java/thumbnailer/image/)

- [ImageProbe.java](../../backend/src/main/java/thumbnailer/image/ImageProbe.java) — `probe(container, name)` / `probe(head, name, Source)` from the first `HEAD` (128 KiB) bytes: `probe(head)` (pure: `Header` for JPEG/TIFF/PNG/GIF/BMP, WebP via its bitstream header, else null), else `read(Source)` (metadata-extractor + ImageIO header, one open; reopens past the head); `Source` = how to open the file again; `exif(head)` (marker walk for JPEG, metadata-extractor otherwise); `decode(stream, name, exif, body)` for the ImageIO fallback; records `Probe`, `Exif`.
- [Header.java](../../backend/src/main/java/thumbnailer/image/Header.java) — `parse(MemorySegment)` → `(width, height, Exif)` from a prefix: JPEG markers to the SOFn (+ APP1 Exif), TIFF IFD0 (size, Orientation, Artist; Exif-IFD DateTimeOriginal; both byte orders), PNG IHDR + `eXIf` before IDAT, GIF logical screen, BMP DIB header; null for other formats, a zero size or facts past the prefix.
- [Thumbnailer.java](../../backend/src/main/java/thumbnailer/image/Thumbnailer.java) — `@C` `render(data, name, Render)` → `Thumb(bytes, format, epoch, portrait)` from the file in memory (the caller reads it, so its disk turn ends before the decode; `render(container, …)` reads in a confined arena first) → JPEG: `TurboJpeg.decode` at the smallest DCT scale ≥ `GAP` (1.5) × target (CMYK/12-bit → ImageIO); WebP: `WebP.decode`; else ImageIO subsampled to ≤ 2× → `Resampler` → `Pixels.oriented` (EXIF 2–8) → `WebP.encode` / `TurboJpeg.encode`; longer side `spec.size`, proportional, no upscale; the constructor loads both natives (fails fast), logs `Resampler.PATH` and starts `Resampler.warmUp` on the daemon thread `resampler-warmup`.
- [TurboJpeg.java](../../backend/src/main/java/thumbnailer/image/TurboJpeg.java) — libjpeg-turbo 3.2 C API over FFM (ordinary `tj3*` downcalls on native memory: a critical 10-50 ms decode held off the other renders' safepoints; buffers from `tj3Alloc`, uninitialized): `isJpeg`, `decode(segment, minLonger)` (DCT scale 1/8, 1/4, 1/2 or 1, full size for lossless JPEGs; fast IDCT + upsampling; `TJPF_BGRX`, one bulk copy into `Pixels`; libjpeg warnings accepted), `encode(Pixels, quality)` (4:2:0, worst-case buffer, no realloc).
- [WebP.java](../../backend/src/main/java/thumbnailer/image/WebP.java) — over the vendored `NativeWebP`: `isWebP features decode` (stills; alpha → white; an animation throws so ImageIO decodes its first frame) `encode` (lossy, single-threaded, BGRX import without a copy).
- [Pixels.java](../../backend/src/main/java/thumbnailer/image/Pixels.java) — record `(argb, width, height)`, packed `0x??RRGGBB`, the one layout decode → resample → encode; `of(BufferedImage)` (ImageIO fallback, on white), `onWhite()`, `oriented(exif)` (index remapping).
- [Render.java](../../backend/src/main/java/thumbnailer/image/Render.java) — spec record `(format WEBP|JPEG, quality 1..100, size 64..4096, threads 0..64)`, `Format.mediaType()`, `permits()` (0 = CPUs), `epoch()` (format/size/quality), `LEGACY_EPOCH` = `(WEBP, 75, 512)`; defaults `COVERS`, `THUMBS`.
- [Limiter.java](../../backend/src/main/java/thumbnailer/image/Limiter.java) — fair `Semaphore` (a waiter may hold a disk turn) with `resize(permits)` (grow = release, shrink = `reducePermits`) and `enter(permits)` (resize + acquire; interrupt → `InterruptedIOException`).
- [Resampler.java](../../backend/src/main/java/thumbnailer/image/Resampler.java) — `resize(Pixels, w, h, boxed[, simd])` both directions, Pillow geometry: power-of-two `box` (2/4/8, cropped to whole boxes, at most 1/64 of an axis) while ≥ 1.9x remains, then Lanczos3 (also for `boxed` = DCT-scaled input), else Keys cubic a = −0.55; Q7 with R|B in 16-bit fields (Q22 for kernels > 24 taps); nested `Simd` (Vector API: shuffle/blend plans up to ratio 4, gathers beyond, SIMD box) used when `SIMD` (module present, C2 available per `c2()`: HotSpot `UseCompiler` and `TieredStopAtLevel` ≥ 4, ≥ 8 int lanes), else scalar loops with the same bits; `warmUp()` runs the SIMD kernel shapes real images take until C2 compiled them (warming tiny gather/Q22 shapes as well left the main shape 3x slower) (interpreted Vector API code made the first album after start 3x slower); `PATH` names the path taken and why. Chosen with [scalebench](../../scalebench/README.md).

## [index/](../../backend/src/main/java/thumbnailer/index/) — scanning

- [AlbumDiscovery.java](../../backend/src/main/java/thumbnailer/index/AlbumDiscovery.java) — `@C` `walk()`: dir with ≥`min-images` images, any archive; skips exclusions/AccessDenied; returns `complete`.
- [AlbumIndexer.java](../../backend/src/main/java/thumbnailer/index/AlbumIndexer.java) — `@C` `index(…, turn, lane)` → `Indexed(album, entries, Thumb cover)`: reads in the album's disk turn, which the first cover read ends (or the end of the reads when the stored cover holds), a further candidate in a new turn; a `cpuBound()` archive gives the turn back after its listing (other albums read while it decompresses); `lane.giveWay()` before each head and each later probe (the scan pauses while the UI reads the disk); reuses stored probes and the stored cover (`storedCover`) for unchanged `(name,bytes,mtime)`, never for a `.cry` entry (a re-index may follow a key change); probes the rest through `container.heads(…, ImageProbe.HEAD)` with the pure `ImageProbe.probe(head)` (one pass for a solid archive, the sink possibly on 7-Zip's threads), the formats that need more afterwards (a `sequential()` archive: all of them in one more `heads` pass, never per file); an archive-wide read failure or an interrupt → empty, so the stored album and signature stay for a retry; candidates render through `AlbumService.renderCover`; stores `Cry.signature(container)`.
- [Reconciler.java](../../backend/src/main/java/thumbnailer/index/Reconciler.java) — `@C` `begin(settings)` (runs `retainRoots` first) `→Pass{load(scope), reconcile(root, canonical path, …, lane, cancelled), prune(scopes)}` (an album's turn on the lane from the container open): unchanged (`Cry.matches`: same files, same `.cry` key)/changed/moved/new/removed; a stored album whose `images()` emptied (all excluded, or `.cry` files without the password) counts as not met and is pruned with its scope; works on prefix `stamps`, loads full albums only to re-index; `moved()` checks the old path through `locate`.
- [ScanService.java](../../backend/src/main/java/thumbnailer/index/ScanService.java) — public `@C` `start(paths) running cancel lastScan freeze frozen` (`freeze()`: volatile, every later `start` is refused until the restart), `scanOnStart`, sync `scan(paths, cancelled)` (tests); one scan at a time, one settings snapshot per scan; `scopes()`: null = every root, else each path a root or below one (`IllegalArgumentException("Not inside an indexed folder: …")`), nested/duplicates fold into the outer, `spelled()`: an existing scope takes the file system's spelling (`toRealPath`, rebased onto the root; gone or reached through a link → as typed), private `Scope(root, path)`; each scope walked at `locate(scope)` (`walk()`), found paths rebased to the canonical scope, exclusions `rebased`; a gone or `excluded()` folder below a reachable root = empty complete walk; `lastScans` only for whole roots; virtual thread per album, `Semaphore(index-threads)` backpressure on the walk; scopes grouped by their root's `Disks.Disk`: groups walked at once on virtual threads `walk-N` (a failed one fails the scan, nothing pruned), scopes of one group in order, `index-threads` albums in flight per disk (a shared limit would let albums queued on an HDD's lane hold an SSD back); each scope reads through its disk's `SCAN` lane (type, key and its own counts in the `Scanned …` log line); `close()` on context close.
- [ScanProgress.java](../../backend/src/main/java/thumbnailer/index/ScanProgress.java) — event record (`root` = scope being walked), throttled ≤4/s.

## [settings/](../../backend/src/main/java/thumbnailer/settings/)

- [Libraries.java](../../backend/src/main/java/thumbnailer/settings/Libraries.java) — `@C` `libraries.json` in home (`data-dir`), nested `State(active, known)`: `home dir active known pinned switchTo forget`; `pinned` = `thumbnailer.library-pinned`, then `switchTo`/`forget` throw `IllegalStateException`; `switchTo` also requires a parseable `settings.json` if present; static `read(file, json)` (unreadable → absent).
- [LibraryLocator.java](../../backend/src/main/java/thumbnailer/settings/LibraryLocator.java) — `ApplicationEnvironmentPreparedEvent` listener: sets `thumbnailer.library-dir` to the active library unless given; sets `thumbnailer.library-pinned` to whether it was given.

## [web/](../../backend/src/main/java/thumbnailer/web/)
