## Data flow

```
Topbar/FiltersPanel ─▶ AlbumStore.text/filters/sort ─(computed query, effect 120ms)─▶ Gateway.search ─▶ albums/total
Sidebar (Browse: group-by) ─▶ FolderTree | EntityTree(kind) ─▶ filters.entities / missing (scope) ─▶ Topbar scope chips, Sidebar scope line; Views strip ─▶ filters.hidden / duplicates
FolderTree/LocationBar/Topbar chip ─▶ AlbumStore.goTo(path) ─▶ filters.roots=[path] (path-prefix filter) ─▶ store.folder ─▶ crumbs, tree reveal
FolderTree (expanded node) / LocationBar (crumb popover) ─▶ Gateway.folders(path) ─▶ Folder[] (cached per node; reloaded on store.treeVersion)
Gateway.events (albumChanged|albumRemoved|scanProgress|connection) ─▶ AlbumStore.onEvent ─▶ refresh() (600ms, max wait 1.5s)
Gateway.events (catalogChanged|opProgress|opResult) ─▶ AlbumStore.onEvent (routes only) ─▶ CatalogStore.onChanged (version, cache, lists, card) / OpsStore.onProgress|onResult
DetailsPanel chip / EntityCard chip ─▶ DetailsPanel.showEntity ─▶ EntityCard ─▶ CatalogStore.openCard ─▶ Gateway.entity; every control ─▶ CatalogStore.trySave (collision → Confirm "Merge into X?" → merge)
AlbumCard ×N badge / DetailsPanel "N copies" ─▶ CatalogStore.copiesOf ─▶ CopiesPopover (in Topbar) ─▶ Gateway.copies / compareCopies
App.tiles (Album→Tile 16:9|9:16) ─▶ TileGrid ─▶ layout() ─▶ visible placements ─▶ <ng-template> AlbumCard
/album/:id ─▶ AlbumViewer (Gateway.album → entries → TileGrid mode=grid + lightbox)
SettingsDialog.draft ─(model)─▶ FoldersPage/ThumbnailsPage ─▶ Save ─▶ AlbumStore.saveSettings ─▶ Gateway.setSettings
LibraryPage/FoldersPage ─▶ FolderPicker.pick() ─▶ app-folder-picker (Gateway.browse) ─▶ path ─▶ switchLibrary / addRoot / pathMap rule
```

## core/ — [src/app/core/](../../frontend/src/app/core/) (no components)

- [model.ts](../../frontend/src/app/core/model.ts) — wire types mirroring the backend: `Album Entry Kind Sort SortField SORT_FIELDS Filters AlbumQuery AlbumPatch AlbumTarget Render Mapping Storage ScanRoot Settings DEFAULT_SETTINGS RootStatus SettingsInfo Folder Listing LibraryStats LibraryInfo ScanProgress Facets SearchResult AlbumDetails GatewayEvent`; catalog `EntityKind ENTITY_KINDS Entity Link EntityQuery EntityList EntityCard EntityLinkOut EntityLinkIn StudioRow Derived EntitySave` (`aliases`/`links` absent or null keep the current set; `Entity.profile` absent when null); photos `ENTRY_META_KNOWN ENTRY_META PhotoMark PhotoMarks PhotoListItem PhotoList MetaRow Comparison`; operations `Op OpKind PackFormat Conflict Preflight PreflightItem OpProgress OpIssue OpResult`; `activeFilterCount()` (a `false` switch is no criterion).
- [gateway.ts](../../frontend/src/app/core/gateway.ts) — abstract `Gateway` (DI token): `events`, `mock`, `search album update scan(paths?) cancelScan getSettings setSettings facets reveal folders browse library switchLibrary forgetLibrary optimize`; catalog `entities entity saveEntity deleteEntities mergeEntities confirmEntities creditAs bulkUpdate link unlink copies compareCopies`; photos `markPhoto photos photoMeta albumText`; operations `preflight runOp cancelOp` (Promises); `coverUrl thumbUrl originalUrl`.
- [ws-gateway.ts](../../frontend/src/app/core/ws-gateway.ts) — `WsGateway`: JSON over `/ws`, id-correlated requests, 30s timeout, reconnect 0.5→10s backoff, emits `connection`; image URLs `/img/{id}/…?v=revision&r=renderEpoch` (epoch remembered from the last settings reply); `target()` turns an `AlbumTarget`/`Op` query into an `AlbumQuery` (limit 500); `entity` sends `entityId` (`id` is the envelope's); forwards `catalogChanged opProgress opResult` (`EVENTS`) and never correlates `OP_EVENTS` by `id` (theirs is the operation's).
- [mock-gateway.ts](../../frontend/src/app/core/mock-gateway.ts) — `MockGateway` (root status `storage`: SSD on `C:` or forced, else HDD): `gate()` ("A scan is running" / "An operation is running", the server's texts) refuses `scan` (also a second one), root/path-map changes, `switchLibrary forgetLibrary optimize`; turns a `cryPassword` into a fake `cryKey`; 180 seeded albums (every 5th with `bio`, a `GENRES` entry on most, `stamp` = hash of the name without day and volume, so a few are copies), canvas-painted covers, `matches()`/`comparator()` mirror server filter/sort (`roots` = path prefixes; hidden only when `hidden`, `duplicates`, `entities`, `missing`, `genres`), fake scan (`scan(paths)` accepted, walks everything); `apply()` = one album save (date/genres/hidden/addTags/removeTags, revision + 1, `catalog.sync`, `albumChanged`); `folders()` from visible album paths, `browse()` over a fake disk (`DISK`, E: root unreachable, copy under `D:/Backups`), `locate()` path-map rewrite, library stats/switch (connection drop + reconnect)/forget/optimize; catalog, photo and op methods delegate to its parts below; exports `rng hash delay gate targets` (as `AlbumRepository.select`: unknown id, > `SELECT_CAP` or no target fail) and the seed name lists to them.
- [mock-catalog.ts](../../frontend/src/app/core/mock-catalog.ts) — `MockCatalog` (owned by `MockGateway`): entities seeded from the name lists (last three models `auto`, alias `Nikka`), lists `English models`/`Best of 2024`; `sync(ids?)` re-resolves album text into `links` (whole-text alias lookup, else split on `,`/`;`, a miss creates an auto entity → `catalogChanged`), recounts `copies` and `entity.albums`; `entities` (limit ≤ 500) `entity saveEntity` (as `Catalog.save`: null/absent `aliases`/`links` keep, rename keeps the old name as alias, the server's refusals and texts — rating, `"<name>" is <owner>; merge instead?`, `Cannot link to N`, kind change, `No entity N` — always `catalogChanged`) `deleteEntities mergeEntities` (a list's favorites follow through `MockPhotos.removeList/remapList`) `confirmEntities creditAs bulkUpdate link unlink` (`relink`: each album once, only those not yet in that state count; roles 1–5 edit the text through the album save, LIST = membership + one `catalogChanged` when any changed) `copies compareCopies isList`; exports `tag` (`AlbumMeta.tag`, also used by the mock's album tags) and `norm(kind, name)` (`Catalog.norm`); card `aliases` = the other names, normalized.
- [mock-ops.ts](../../frontend/src/app/core/mock-ops.ts) — `MockOps`: `preflight` (skips "already packed"/"already unpacked", free 50 GB), `run` (gate: scan / running op / missing target / "Nothing to do"; `opProgress` per item every 150 ms, one `opResult`), `cancel`, `busy`; effects PACK/UNPACK path + kind, REPACK/CRYPT revision, MOVE/FOLDER_* path rewrites (`albumRemoved` outside every root), COPY/FOLDER_COPY new albums, DELETE `albumRemoved`; `OpsHost` = scanning/roots/sync.
- [mock-photos.ts](../../frontend/src/app/core/mock-photos.ts) — `MockPhotos`: sparse marks per album (seeded on every 9th), `marksOf markPhoto` (server refusals: `No album`, `No entry X`, `Rating must be 0..10`, `No favorites list N` via the `isList` hook) `photos(listId)` (a missing list = `No favorites list N`) `count(listId) remapList removeList` (merge/delete of a list) `photoMeta` (fake EXIF, none without `ENTRY_META`) `albumText` (a bio for `album.bio`).
- [store.ts](../../frontend/src/app/core/store.ts) — `AlbumStore` (root, single state holder): signals `text filters sort albums total loading selectedId hoveredId facets scan settings library connected treeVersion` (bumped on scan end / reconnect / settings saved / op result); computed `query` (parsed text ⊕ filters, `PAGE`=120), `folder` (= `filters.roots[0]`), `refining` (active filters minus the folder), `roots`; `goTo(path) rootOf(path) resetRefine clearFilters refresh loadMore patch reveal startScan(paths?) cancelScan saveSettings loadSettings loadLibrary switchLibrary forgetLibrary optimize loadFacets`; private `applySettings` (load and save: drops a folder under no root), `runSearch` (generation guard), `selection` (a `Selection`, pruned on `albumRemoved`); `onEvent` (also routes `catalogChanged` → `CatalogStore.onChanged` + refresh + facets, `opProgress`/`opResult` → `OpsStore`, reconnect → `onChanged(ENTITY_KINDS)`).
- [catalog-store.ts](../../frontend/src/app/core/catalog-store.ts) — `CatalogStore` (root): `version` (bumped by `onChanged`), `lists` (`loadLists()` lazily, reloaded on LIST changes), `card`/`cardId` + `openCard closeCard`, `copiesOf` (album of the copies popover), `known` (every entity a page or card named, by id: `entityOf(id)`, `ensureKnown(ids)` fetches the missing ones once), `entities(kind, opts)` (≤ 24 cached pages, cleared on change), mutations `save delete merge confirm creditAs link unlink bulkUpdate` (null on failure, toast; `save delete merge confirm creditAs` call `onChanged` on success, `bulkUpdate` too when the patch touches `hidden`, so cached pages and the open card never wait for the event), `trySave`/`tryCreditAs` (the same without the toast: the card turns a `"<name>" is <owner>; merge instead?` refusal, parsed by static `takenBy`, into a merge offer).
- [ops-store.ts](../../frontend/src/app/core/ops-store.ts) — `OpsStore` (root): `progress lastResult`, `preflight run` (null + toast when refused) `cancel onProgress onResult` (summary toast).
- [selection.ts](../../frontend/src/app/core/selection.ts) — `Selection` (pure, signals only): `ids size has click(id, order, {ctrl, shift}) selectAll selectFirst clear set`; `SELECT_CAP` 500 applied to every write.
- [folder-picker.ts](../../frontend/src/app/core/folder-picker.ts) — `FolderPicker` (root): `pick({ title, startAt?, allowNew? }) → Promise<string | null>`, `open` signal read by `ui/settings/folder-picker.ts`, `choose() cancel()`; a new `pick` settles the pending one with null.
- [search-syntax.ts](../../frontend/src/app/core/search-syntax.ts) — `parseSearch()`: `#tag`, `model:|m:`, `studio:|s:`, `by:|photographer:|p:`, `kind:zip|archive|rar|7z|tar|iso|dir` (archive formats → `ARCHIVE`), quoted values; rest = text.
- [layout.ts](../../frontend/src/app/core/layout.ts) — pure engine `layout(tiles,{width,columns,gap,mode})→{placements,height}`; modes `bricks|grid`; `responsiveColumns()`; `MAX_SCALE` 0.15.
- [entity-fields.ts](../../frontend/src/app/core/entity-fields.ts) — pure, Angular-free: `FIELDS` (profile field schema per kind, catalog_plan.md §7.3: `Field {key, label, type text|number|year|chips|textarea, unit?, hint?}`), `parseProfile withField` (the `Entity.profile` JSON; empties drop the key, nothing left = null), `ageFrom` (`YYYY`, `YYYY-MM`, `YYYY-MM-DD`), `cmToFtIn kgToLb`, `parseChips`, `parseNames joinNames` (the album text fields' name-list syntax, `Names.parse/join`).
- [prefs.ts](../../frontend/src/app/core/prefs.ts) — `Prefs`: persisted signals (localStorage `thumbnailer.*`): `theme` (light|dark, first run = OS theme, `toggleTheme()`) `columns layoutMode(key "layout") showTags followHover sidebar('folders'|'refine'|'none', validated) detailsOpen groupBy(GROUP_BYS) viewerScale(VIEWER_SCALES) viewerSort(VIEWER_SORTS) viewerMinSide slideshowSeconds` (enumerations validated); theme effect sets `html[data-theme]`.
- [toasts.ts](../../frontend/src/app/core/toasts.ts) — `Toasts`: `show() error() dismiss()`.
- [format.ts](../../frontend/src/app/core/format.ts) — `formatBytes formatMegapixels`; pipes `bytes mp basename`.
- [paths.ts](../../frontend/src/app/core/paths.ts) — `normPath()` (backslashes → '/', no trailing slash, bare drive keeps 'C:/'), `lastSegment()`, `dir()` (trailing '/'), `commonSuffixMapping(stored, found)` (Locate… rule; prefixes cut from the original strings, so '/' and 'C:/' survive); shared by the folders page, tree and location bar.
