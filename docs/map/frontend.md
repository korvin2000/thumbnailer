## Data flow

```
Topbar/FiltersPanel ─▶ AlbumStore.text/filters/sort ─(computed query, effect 120ms)─▶ Gateway.search ─▶ albums/total
Topbar Catalog ▾ (kind) ─▶ EntityPicker (search, Recent, Create …) ─▶ Actions.openCard ─▶ CatalogStore.openCard ─▶ EntityCard in the details panel (⋯ = Show albums · Credited as… · Merge into… · Delete…)
Sidebar (Browse: group-by) ─▶ FolderTree | EntityTree(kind) ─▶ filters.entities / missing (scope) ─▶ Topbar scope chips, Sidebar scope line; Views strip ─▶ filters.hidden / duplicates
FolderTree/LocationBar/Topbar chip ─▶ AlbumStore.goTo(path) ─▶ filters.roots=[path] (path-prefix filter) ─▶ store.folder ─▶ crumbs, tree reveal
FolderTree (expanded node) / LocationBar (crumb popover) ─▶ Gateway.folders(path) ─▶ Folder[] (cached per node; reloaded on store.treeVersion)
Gateway.events (albumChanged|albumRemoved|scanProgress|connection) ─▶ AlbumStore.onEvent ─▶ refresh() (600ms, max wait 1.5s)
Gateway.events (catalogChanged|opProgress|opResult) ─▶ AlbumStore.onEvent (routes only) ─▶ CatalogStore.onChanged (version, cache, lists, card) / OpsStore.onProgress|onResult ─▶ statusbar progress + Cancel; issues ─▶ App result dialog (Confirm)
TileGrid.contextMenu / LocationBar chip ▾ / FolderTree.contextMenu / EntityTree.contextMenu ─▶ Actions.open*Menu ─▶ menus.ts builders (Target = selection | node query) ─▶ ContextMenu ─▶ Actions.* ─▶ CatalogStore.link|unlink|bulkUpdate (assign, favorites, rating, date, hide) | OpsStore.preflight ─▶ Confirm (op-confirm.ts) ─▶ OpsStore.run
EntityCard "Show photos" / EntityTree LIST row ─▶ /list/:id PhotoListView ─▶ Gateway.photos ─▶ /album/:id?photo=<index> (lightbox on that entry)
DetailsPanel chip / EntityCard chip / tree "Open card" / viewer link ─▶ CatalogStore.openCard (cardId = the panel's entity mode) ─▶ EntityCard ─▶ Gateway.entity; every control ─▶ CatalogStore.trySaveCard (queued, built from the card when sent; collision → Confirm "Merge into X?" → merge)
AlbumCard ×N badge / DetailsPanel "N copies" ─▶ CatalogStore.copiesOf ─▶ CopiesPopover (in app.html) ─▶ Gateway.copies / compareCopies; deleteRequested ─▶ App.deleteCopy ─▶ Actions.delete
App.tiles (Album→Tile 16:9|9:16) ─▶ TileGrid ─▶ layout() ─▶ visible placements ─▶ <ng-template> AlbumCard
/album/:id ─▶ AlbumViewer (lazy route; Gateway.album → entries → TileGrid mode=grid + lightbox)
Topbar brand / `thumbnailer:settings` event / viewer "Edit targets…" ─▶ SettingsLink.open(page) ─▶ @defer app-settings-dialog (loaded once) ─▶ SettingsDialog.open(page)
SettingsDialog.draft ─(model)─▶ FoldersPage/ThumbnailsPage ─▶ Save ─▶ AlbumStore.saveSettings ─▶ Gateway.setSettings
LibraryPage/FoldersPage ─▶ FolderPicker.pick() ─▶ app-folder-picker (Gateway.browse) ─▶ path ─▶ switchLibrary / addRoot / pathMap rule
```

## core/ — [src/app/core/](../../frontend/src/app/core/) (no components)

- [model.ts](../../frontend/src/app/core/model.ts) — wire types mirroring the backend: `Album AlbumRef Entry Kind Sort SortField SORT_FIELDS Filters AlbumQuery AlbumPatch AlbumTarget Render Mapping Storage ScanRoot Settings DEFAULT_SETTINGS RootStatus SettingsInfo Folder Listing LibraryStats LibraryInfo ScanProgress Facets SearchResult AlbumDetails GatewayEvent`; catalog `EntityKind ENTITY_KINDS Entity Link EntityQuery EntityList EntityCard EntityLinkOut EntityLinkIn StudioRow Derived EntitySave` (`aliases`/`links` absent or null keep the current set; `Entity.profile` absent when null; `EntityQuery.unused` = auto entities no album links to, hidden ones included); photos `ENTRY_META_KNOWN ENTRY_META PhotoMark PhotoMarks PhotoListItem PhotoList MetaRow Comparison`; operations `Op OpKind PackFormat Conflict Preflight PreflightItem OpProgress OpIssue OpResult` (`Preflight.keyVerified`: the session key decrypted an existing `.cry` of an encrypt selection); `activeFilterCount()` (a `false` switch is no criterion).
- [gateway.ts](../../frontend/src/app/core/gateway.ts) — abstract `Gateway` (DI token): `events`, `mock`, `search album update scan(paths?) cancelScan getSettings setSettings facets reveal(albumId | null, path?) folders browse library switchLibrary forgetLibrary optimize`; catalog `entities entity saveEntity deleteEntities mergeEntities confirmEntities creditAs bulkUpdate link unlink copies compareCopies`; photos `markPhoto photos photoMeta albumText`; operations `preflight runOp cancelOp` (Promises); `coverUrl(Album) thumbUrl originalUrl` (an `AlbumRef`: id + revision, so a list's photos need no full album).
- [ws-gateway.ts](../../frontend/src/app/core/ws-gateway.ts) — `WsGateway`: JSON over `/ws`, id-correlated requests, 30s timeout (10 min for `compareCopies` and `preflight`, which read whole albums), reconnect 0.5→10s backoff, emits `connection`; a request made while the socket is down (the restart after an optimize or a library switch) stays queued (`Pending.sent`) and goes out on the next `onopen` — only sent requests fail with "Connection lost", an unsent one times out as "Not connected"; image URLs `/img/{id}/…?v=revision&r=renderEpoch` (epoch remembered from the last settings reply); `target()` turns an `AlbumTarget`/`Op` query into an `AlbumQuery` (limit 500); `entity` sends `entityId` (`id` is the envelope's), `entities` sends `unused: true` only when set, `reveal` adds `path` only when given; forwards `catalogChanged opProgress opResult` (`EVENTS`) and never correlates `OP_EVENTS` by `id` (theirs is the operation's).
- [mock-gateway.ts](../../frontend/src/app/core/mock-gateway.ts) — `MockGateway` (root status `storage`: SSD on `C:` or forced, else HDD; `Resolver` = name → entity id through aliases, `find` from `MockCatalog.idOf`): `gate()` ("A scan is running" / "An operation is running", the server's texts) refuses `scan` (also a second one), root/path-map changes, `switchLibrary forgetLibrary optimize`; turns a `cryPassword` into a fake `cryKey`; 180 seeded albums (every 5th with `bio`, a `GENRES` entry on most, `stamp` = hash of the name without day and volume, so a few are copies), canvas-painted covers, `matches(a, q, find)`/`comparator()` mirror server filter/sort (`roots` = path prefixes; `kind: ARCHIVE` = every archive kind; hidden only when `hidden`, `duplicates`, `entities`, `missing`; `model/studio/photographer/tags/genres` = whole names through any alias → link, unknown name → nothing), fake scan (`scan(paths)` accepted, walks everything); `apply()` = one album save (date/genres/hidden/addTags/removeTags, revision + 1, `catalog.sync`, `albumChanged`); `folders()` from visible album paths, `browse()` over a fake disk (`DISK`, E: root unreachable, copy under `D:/Backups`), `locate()` path-map rewrite, library stats/switch (connection drop + reconnect)/forget/optimize, `facets()` counted from the links (primary names), `compareCopies` → `error "busy"` while an operation runs; catalog, photo and op methods delegate to its parts below (`renameRoot` keeps the settings root of a renamed root folder, `key` hands them the fake session key); exports `rng hash delay gate targets(albums, t, find)` (as `AlbumRepository.select`: unknown id, > `SELECT_CAP` or no target fail) and the seed name lists to them.
- [mock-catalog.ts](../../frontend/src/app/core/mock-catalog.ts) — `MockCatalog` (owned by `MockGateway`): entities seeded from the name lists (last three models `auto`, alias `Nikka`), lists `English models`/`Best of 2024`; `sync(ids?)` re-resolves album text into `links` (whole-text alias lookup, else split on `,`/`;`, a miss creates an auto entity → `catalogChanged`), recounts `copies` and `entity.albums`; `entities` (limit ≤ 500; under another entity: those sharing visible albums with it, `albums` = the shared count, sort COUNT by it; `unused` = auto entities with no link at all, hidden albums included) `entity` (card `derived` per kind as B1: model → studios/photographers/genres/tags, studio → models/photographers/genres, photographer → models/studios/genres, genre/tag → models/studios, list → albums only; related entities carry the shared count, most first, ≤ `DERIVED` 100) `saveEntity` (as `Catalog.save`: null/absent `aliases`/`links` keep, rename keeps the old name as alias, the server's refusals and texts — rating, `"<name>" is <owner>; merge instead?`, `Cannot link to N`, kind change, `No entity N` — always `catalogChanged`) `deleteEntities mergeEntities` (the survivor's profile wins field by field, a list's favorites follow through `MockPhotos.removeList/remapList`, nothing to merge refused) `confirmEntities creditAs bulkUpdate link unlink` (`relink`: each album once, only those not yet in that state count; roles 1–5 edit the text through the album save, LIST = membership + one `catalogChanged` when any changed) `copies compareCopies isList idOf`; exports `tag` (`AlbumMeta.tag`, also used by the mock's album tags) and `norm(kind, name)` (`Catalog.norm`); card `aliases` = the other names, normalized.
- [mock-ops.ts](../../frontend/src/app/core/mock-ops.ts) — `MockOps`: `preflight` (skips "already packed"/"already unpacked", "needs the password" for a CRYPT without `op.password` or a session key, free 50 GB; `keyVerified` for an encrypt with the session key when a target album was encrypted here before — the `encrypted` set stands in for `.cry` files), `run` (gate: scan / running op / missing target / "Nothing to do"; `opProgress` per item every 150 ms, one `opResult`), `cancel`, `busy`; effects PACK/UNPACK path + kind, REPACK/CRYPT revision (CRYPT also marks or unmarks the album encrypted), MOVE/FOLDER_* path rewrites (`albumRemoved` outside every root; a renamed root first renames the settings root through `OpsHost.renameRoot`), COPY/FOLDER_COPY new albums, DELETE `albumRemoved`; `OpsHost` = scanning/roots/sync/find/renameRoot/key.
- [mock-photos.ts](../../frontend/src/app/core/mock-photos.ts) — `MockPhotos`: sparse marks per album (seeded on every 9th), `marksOf markPhoto` (server refusals: `No album`, `No entry X`, `Rating must be 0..10`, `No favorites list N` via the `isList` hook) `photos(listId)` (a missing list = `No favorites list N`) `count(listId) remapList removeList` (merge/delete of a list) `photoMeta` (fake EXIF, none without `ENTRY_META`) `albumText` (a bio for `album.bio`).
- [store.ts](../../frontend/src/app/core/store.ts) — `AlbumStore` (root, single state holder): signals `text filters sort albums total loading selectedId hoveredId facets scan settings library connected treeVersion` (bumped on scan end / reconnect / settings saved / op result); computed `query` (parsed text ⊕ filters, `PAGE`=120), `folder` (= `filters.roots[0]`), `refining` (active filters minus the folder), `roots`; `goTo(path) rootOf(path) resetRefine clearFilters refresh loadMore patch reveal(id | null, path?) startScan(paths?) cancelScan saveSettings(s, done?) loadSettings loadLibrary switchLibrary forgetLibrary optimize loadFacets`; private `applySettings` (load and save: drops a folder under no root; another `dataDir` = another library: the entity scope goes and `CatalogStore.reset()`), `runSearch` (generation guard), `replace(album)` (a patch reply or `albumChanged` never puts an older `revision` over the one shown), `selection` (a `Selection`, cleared by the query effect — other albums — and pruned on `albumRemoved`; a `refresh` keeps it); `onEvent` (also routes `catalogChanged` → `CatalogStore.onChanged` + refresh + facets, `opProgress`/`opResult` → `OpsStore`, every `opResult` reloads the settings (a renamed root), the tree and the catalog pages (deleted albums leave the counts), reconnect → `onChanged(ENTITY_KINDS)`).
- [catalog-store.ts](../../frontend/src/app/core/catalog-store.ts) — `CatalogStore` (root): `version` (bumped by `onChanged`), `lists` (`loadLists()`: one request shared by every caller, reloaded on LIST changes with a generation so the fresh answer wins), `card`/`cardId` + `openCard closeCard`, `copiesOf` (album of the copies popover), `known` (every entity a page or card named, by id: `entityOf(id)`, `ensureKnown(ids, refresh?)` fetches the missing ones once — or all of them again — and resolves with the ids the server answers `No entity N` for), `reset()` (another library: pages, names, lists and the card go), `entities(kind, opts)` (≤ 24 cached pages, cleared on change), mutations `save delete merge confirm creditAs link unlink bulkUpdate` (null on failure, toast; `save delete merge confirm creditAs` call `onChanged` on success, `link`/`unlink` for the entity's kind and `bulkUpdate` when the patch touches `hidden`, so cached pages and the open card never wait for an event that the server does not send for counts), `trySave`/`tryCreditAs` (the same without the toast: the card turns a `"<name>" is <owner>; merge instead?` refusal, parsed by static `takenBy`, into a merge offer), `trySaveCard(patch)` (the open card's saves queued one after the other, each built from the card as the previous reply left it; a null patch sends nothing).
- [ops-store.ts](../../frontend/src/app/core/ops-store.ts) — `OpsStore` (root): `progress current` (`{ id, op }`: the op started here under the id the server gave it) `lastResult issues` (a result with skipped/failed items, taken by the app's result dialog), `preflight run` (null + toast when refused) `cancel onProgress opOf` (by id, not kind: another client's op is its kind alone) `kindOf(id) onResult` (a clean result = toast); pure `opNoun opVerb` ("Pack" / "Packing", `CRYPT` by `encrypt`, "Encrypt/decrypt" when unknown).
- [selection.ts](../../frontend/src/app/core/selection.ts) — `Selection` (pure, signals only): `ids size has click(id, order, {ctrl, shift}) selectAll selectFirst clear set`; `SELECT_CAP` 500 applied to every write.
- [folder-picker.ts](../../frontend/src/app/core/folder-picker.ts) — `FolderPicker` (root): `pick({ title, startAt?, allowNew? }) → Promise<string | null>`, `open` signal read by `ui/settings/folder-picker.ts`, `choose() cancel()`; a new `pick` settles the pending one with null.
- [search-syntax.ts](../../frontend/src/app/core/search-syntax.ts) — `parseSearch()`: `#tag`, `model:|m:`, `studio:|s:`, `by:|photographer:|p:`, `kind:zip|archive|rar|7z|tar|iso|dir` (archive formats → `ARCHIVE`), quoted values; rest = text.
- [layout.ts](../../frontend/src/app/core/layout.ts) — pure engine `layout(tiles,{width,columns,gap,mode})→{placements,height}`; modes `bricks|grid`; `responsiveColumns()`; `MAX_SCALE` 0.15.
- [entity-fields.ts](../../frontend/src/app/core/entity-fields.ts) — pure, Angular-free: `FIELDS` (profile field schema per kind, catalog_plan.md §7.3: `Field {key, label, type text|number|year|chips|textarea, unit?, hint?}`), `parseProfile withField` (the `Entity.profile` JSON; empties drop the key, nothing left = null), `ageFrom` (`YYYY`, `YYYY-MM`, `YYYY-MM-DD`), `cmToFtIn kgToLb`, `parseChips`, `parseNames joinNames` (the album text fields' name-list syntax, `Names.parse/join`).
- [prefs.ts](../../frontend/src/app/core/prefs.ts) — `Prefs`: persisted signals (localStorage `thumbnailer.*`): `theme` (light|dark, first run = OS theme, `toggleTheme()`) `columns layoutMode(key "layout", `toggleLayout()`) showTags followHover sidebar('folders'|'refine'|'none', validated) lastTab (the tab shown last, kept by an effect; `toggleSidebar()` closes or reopens on it) detailsOpen groupBy(GROUP_BYS) viewerScale(VIEWER_SCALES) viewerSort(VIEWER_SORTS) viewerSortDesc viewerMinSide slideshowSeconds` (enumerations validated); theme effect sets `html[data-theme]`.
- [toasts.ts](../../frontend/src/app/core/toasts.ts) — `Toasts`: `show() error() dismiss()`.
- [format.ts](../../frontend/src/app/core/format.ts) — `formatBytes formatMegapixels`; pipes `bytes mp basename`.
- [paths.ts](../../frontend/src/app/core/paths.ts) — `normPath()` (backslashes → '/', no trailing slash, bare drive keeps 'C:/'), `lastSegment()`, `dir()` (trailing '/'), `commonSuffixMapping(stored, found)` (Locate… rule; prefixes cut from the original strings, so '/' and 'C:/' survive); shared by the folders page, tree and location bar.

- [sidebar.ts](../../frontend/src/app/ui/sidebar.ts) — `Sidebar`: 44px header = one `.segmented.tabs` strip that fits the panel (flex, ellipsis): the Browse segment reads "Browse" while Refine shows and, once active, the current group with a caret (`GROUPS`: Folders · Studios · Models · Photographers · Genres · Favorites → `Prefs.groupBy`, menu through `ContextMenu.open` with the current one checked; `menuOpen` turns the caret while that menu shows) | Refine (badge); an icon Reset (`store.resetRefine`, Refine only) and close ×; a scope line under the header while `filters.entities`/`missing` narrow the grid ("Models › Name · N", × clears both; the location bar shows folders only); body = `app-folder-tree` (Folders), `app-entity-tree [kind]` (the rest) or `app-filters-panel`, both trees' `(contextMenu)` → `Actions.openFolderMenu` / `openEntityMenu`; below the tree the fixed **Views** strip: Hidden (count, "Unhide all" = `CatalogStore.bulkUpdate({ query: { hidden: true } }, { hidden: false })`, then settings + tree reload) and Duplicates (count) toggling `filters.hidden` / `filters.duplicates`; `counts` = two one-row searches, re-run (700 ms) on `catalog.version`, `treeVersion` and result changes.
- [entity-tree.ts](../../frontend/src/app/ui/entity-tree.ts) — `EntityTree` (`app-entity-tree`, input `kind`): rows All (library total) · Unassigned (`missing` count from one search) · entities from `CatalogStore.entities(kind, { byCount?, offset, limit 100 })` (name, stored count, auto dot + dimmed name, "N more…" paging), a second level where the server answers `under` (`UNDER`: studio › models, model › studios, photographer/genre › models; a chevron only on rows with albums — children share one — and an opened row without any shows a dimmed "No models" line (`Row.empty`, never picked); the first "not implemented" hides the chevrons), filter box (local substring over a complete list, server prefix search while the list is paged), sort by name/count, header "Delete unused…" (every page of the server's `unused` filter — auto entities no album links to, hidden ones included; refused with a toast when a server without the filter answers used ones); plain click = scope (`filters.entities = [id]`, a child row `[parent, child]`, Unassigned = `filters.missing = kind`) and the only selected row, Ctrl/Shift = `Selection` only (no toolbar: the batch flows are the row's context menu over the selected rows, and the Delete key, which waits while the selection `mixed`es parents and children; collapsing a row drops its children from the selection; a done flow clears the rows); right-click emits `contextMenu: EntityTreeContext {kind (a child row's own), entity | null, missing, scope, selected (of that kind), x, y}` (the row joins the selection first); keys ↑ ↓ → ← Home End Esc Delete Ctrl+A (handled keys stop before `App.onKey`); reloads on `catalog.version` / `treeVersion`, keeping the pages already asked for; re-exports `KIND_ICON KIND_LABEL NOUN` from [kinds.ts](../../frontend/src/app/ui/kinds.ts).
